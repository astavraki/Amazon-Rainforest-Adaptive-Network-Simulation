# Amazon-Rainforest-Adaptive-Network-Simulation

This project contains a Python simulation developed for an assignment on adaptive networks in climate systems.

The simulation explores how drought affects moisture transport and forest density in a simplified model of the Amazon rainforest.

Two networks are compared:

- **Adaptive network (North):** Moisture connections change with forest density and can break or reform.
- **Fixed-coupling network (South):** Moisture connections remain constant.

The simulation includes an interactive time slider, adjustable drought intensity, and a graph comparing forest density over time.

## How to run

1. Download the Python file.
2. Make sure Python 3 with Tkinter is installed.
3. Run the following command:

`python amazon_north_adaptive_south.py`

No additional Python packages are required.
